# Notes API

REST API для заметок с JWT-авторизацией. Пет-проект на Java и Spring Boot.

## Стек

- **Java 21**
- **Spring Boot 4.1**
- **Spring Security 7** + JWT
- **Spring Data JPA** + Hibernate
- **PostgreSQL 16**
- **Flyway** — миграции БД
- **Lombok**
- **Maven**

## Что реализовано

- REST API для пользователей (полный CRUD)
- JWT-авторизация: регистрация, логин, защищённые эндпоинты
- Хеширование паролей через BCrypt
- Глобальная обработка исключений
- Миграции БД через Flyway
- DTO-слой — entity не уходят наружу
